# 美身堂　えいち鍼灸院 予約システム

追加ライブラリなしで動く、LINE公式から案内できる予約システムです。

GitHubで管理する場合の推奨リポジトリ名は `eichi-line-reservation` です。

## できること

- お客様がメニュー、日付、時間を選んで予約できる
- お客様がカレンダーで空き状況を確認できる
- 空き時間ボタンから予約日時を選べる
- 管理画面で営業時間、定休日、不定休、日別営業時間を変更できる
- 管理画面で特定日の特定時間を30分単位で予約ブロックできる
- 管理画面で基本メニュー、治療の簡易説明、料金、所要時間を変更できる
- オプションメニューを追加できる
- 名前、電話番号、メール、相談内容を保存できる
- 予約の重複を防げる
- 管理画面ログインで予約情報を保護できる
- 管理画面で週カレンダー形式の予約状況を見られる
- 管理画面で時間割ごとに予約、施術中、予約ブロック、空きを確認できる
- 管理画面の週カレンダーから、予約追加や外出・休憩・勉強会などの別予定ブロックができる
- お客様側には予約内容や管理メモを出さず、予約不可の時間としてだけ表示できる
- お客様側の予約画面は、メニュー、日付、時間、お客様情報、確認、完了のステップで進められる
- 患者さん向け画面は和モダン、管理画面は週カレンダー中心の見やすい予約管理画面にしている
- 管理画面で予約一覧を見られる
- 予約をキャンセル扱いにできる
- CSVで予約一覧を書き出せる
- 予約後にGoogleカレンダー、iPhone/Macカレンダーへ追加できる
- 予約通知ログを管理画面で確認できる
- 個人情報の取り扱いページを表示できる

## 起動方法

```zsh
cd /Users/aran/Documents/Codex/2026-07-31/z/work/reservation-system
npm start
```

起動したら、ブラウザで開きます。

- 予約ページ：http://localhost:3000
- 管理画面：http://localhost:3000/admin.html

別のアプリが `3000` 番を使っている場合は、ポートを変えて起動できます。

```zsh
PORT=3010 npm start
```

- 予約ページ：http://localhost:3010
- 管理画面：http://localhost:3010/admin.html

## 設定を変える場所

管理画面から変更できます。

- 予約ページ：http://localhost:3000
- 管理画面：http://localhost:3000/admin.html

初期ログインパスワードは、ローカルの `data/db.json` または環境変数 `ADMIN_PASSWORD` で管理します。外部公開前に必ず強いパスワードへ変更してください。

管理画面の「管理パスワード変更」からも変更できます。変更後はいったんログアウトされ、新しいパスワードで再ログインします。

管理画面の「管理者メール」は、パスワード再設定申請に使うメールアドレスです。メール送信サービスを接続するまでは、申請ログとして管理画面に残ります。

不定休は `2026-05-20` のように1行に1日ずつ入力します。

日別営業時間は `2026-05-21,10:00,16:00` のように、日付、開始時間、終了時間をカンマ区切りで入力します。

時間ブロックは、管理画面の「時間ブロック」で日付を選び、30分ごとのボタンを押してから「設定を保存」します。

## 直接設定を変える場所

`data/db.json` の中を編集します。このファイルには予約者情報が入るため、GitHubには上げません。GitHubには個人情報を含まない `data/db.example.json` だけを保存します。

- `clinicName`：治療院名
- `description`：予約ページの説明文
- `openTime`：受付開始時間
- `closeTime`：管理カレンダー上の終了時間
- `lastReceptionTime`：最終受付時間
- `closedWeekdays`：定休日
- `menus`：メニュー名、時間、料金、説明

## LINE公式で使う流れ

1. 予約システムを公開サーバーに置く
2. 公開URLを発行する
3. LINE公式アカウントのリッチメニュー、プロフィール、自動応答に予約URLを貼る
4. 患者さんはLINEから予約ページを開いて予約する
5. 管理者は `/admin.html` で予約・ブロック・キャンセルを管理する

詳しい公開前チェックは `docs/LINE_RELEASE_CHECKLIST.md` を確認します。

## GitHubに上げないもの

- `data/db.json`
- `.env`
- 予約者の名前、電話番号、メールアドレス
- 管理画面ログインセッション

GitHubリポジトリ作成時のメモは `docs/GITHUB_SETUP.md` にまとめています。

曜日の数字は以下です。

```text
0 日曜
1 月曜
2 火曜
3 水曜
4 木曜
5 金曜
6 土曜
```
