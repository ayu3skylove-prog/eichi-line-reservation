### 要件②：Gmail連携による「予約確定メール」自動送信
患者さんが予約を完了した際、自動でGmail経由で予約確定メールが送信されるようにする。

#### 1. 送信先とメール内容
1. **患者さん宛て（予約確定メール）**:
   - 件名：`【美身堂えいち鍼灸院】ご予約ありがとうございます（予約完了）`
   - 本文内容：
     - 患者様のお名前（◯◯ 様）
     - ご予約日時（◯月◯日 ◯◯:◯◯〜）
     - ご予約メニュー名・所要時間・料金
     - オプション名・所要時間（ある場合）
     - お支払いのご案内：「※施術当日、受付にて現金にてお願い申し上げます。」
     - サロン情報（美身堂えいち鍼灸院、愛媛県松山市、院長 松岡あゆみ）
     - キャンセル・変更に関するご案内（公式LINEまたはお電話へ）
2. **院長宛て（新規予約通知メール）**:
   - 件名：`【美身堂えいち】新規予約通知: ◯◯様（◯月◯日 ◯◯:◯◯）`
   - 本文内容：患者名、電話番号、メールアドレス、希望日時、メニュー、オプション、相談内容（メモ）。

#### 2. システム実装（`server.js` ＆ `data/db.json`）
- `server.js` に Gmail SMTP（`smtp.gmail.com:465` SSL / または `tls`）送信ロジックを実装。
- `data/db.json` の `settings` に以下の設定項目を追加・保持：
  - `gmailUser`: 送信元のGmailアドレス（例: `eichi.bishindo@gmail.com` 等）
  - `gmailAppPassword`: Googleの16桁アプリパスワード
  - `notifyEmail`: 院長の通知受信用メールアドレス（未設定時は `gmailUser` 宛て）
- 予約完了処理（`POST /api/bookings`）が成功した直後に非同期でメールを送信し、送信結果（成功・失敗）をログ（`db.notifications`）に記録する。
- 万一Gmail設定が未完了またはエラーの場合でも、予約自体は正常に完了してエラーレスポンスにならないよう安全にフォールバック（try-catch）する。

#### 3. 管理画面（`public/admin.html` ＆ `public/admin.js`）
- 管理画面の「設定」セクションに**「Gmail自動送信設定」**フォームを追加：
  - Gmailアドレス（送信元）
  - Gmailアプリパスワード（16桁・伏字入力対応）
  - 「テスト送信」ボタン（設定が正しいか院長宛てに即座にテストメールを送信する機能）
