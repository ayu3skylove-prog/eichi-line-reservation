# LINE予約システム 公開チェックリスト

## GitHub

- リポジトリ名: `eichi-line-reservation`
- 公開範囲: Private推奨
- GitHubに上げる: ソースコード、画面ファイル、`data/db.example.json`
- GitHubに上げない: `data/db.json`、`.env`、予約者情報、ログインセッション

## 公開前に必ず設定する

- `ADMIN_PASSWORD` を強いパスワードにする
- 個人情報の取り扱いページの事業者情報を確認する
- 問い合わせ電話番号またはメールを設定する
- メニュー名、料金、所要時間を確定する
- 受付開始 `11:00`、最終受付 `18:00`、1日上限 `5枠` を確認する
- 予約データのバックアップ方法を決める

## LINE公式に貼る場所

- リッチメニュー: 「予約する」ボタン
- プロフィール: 予約URL
- あいさつメッセージ: 予約URL
- 自動応答: 「予約」「空き状況」などに予約URLを返信

## 公開後の確認

- スマホで予約ページを開ける
- 予約が登録できる
- 同じ時間に重複予約が入らない
- 治療時間 + 30分の枠が潰れる
- 管理画面で予約が見える
- 管理画面から予約ブロックできる
- CSV出力できる

## しんきゅうコンパスから切り替える前に

- 1週間ほど並行運用する
- LINE公式からの予約導線を固定する
- 既存患者さんへ予約方法変更を案内する
- トラブル時の手動受付方法を決める
